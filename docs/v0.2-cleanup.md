# v0.2 dead-code cleanup

Phase 7 pruned source files orphaned by the v0.2 viewer overhaul. After
`fix/viewer-default-entry` (#130) repointed `demo/index.html` at the
5-beat viewer, the entire "minimal shell" UI (Runbook / Museum
calibration / Step / Overlay modes) became unreachable from the build
and from any `src/` code.

Rather than leave a parallel-but-dead UI in the tree (two paths to read
and reason about when there is really just one), the dead files were
deleted. The git history preserves them for archaeology — see the
commits referenced below.

## What was removed

**`demo/` shell (commit `0102552`):**

| Path | Role in old shell |
| --- | --- |
| `demo/main.ts` | Shell entry script |
| `demo/style.css` | Shell stylesheet |
| `demo/alignmentView.ts` | Alignment view component |
| `demo/museum.ts` | Museum calibration mode logic |
| `demo/summary.ts` | Summary computation |
| `demo/export.ts` | CSV/JSON/MD download helpers |
| `demo/overlay.ts` | Old overlay (distinct from `src/viewer/overlay/`) |
| `demo/printRunSheet.ts` | Print/PDF logic |
| `demo/routing.ts` | Shell routing |
| `demo/runState.ts` | Shell run-state management |
| `demo/export.test.ts` | Tests for removed export helpers |
| `demo/museum.test.ts` | Tests for removed museum module |
| `demo/summary.test.ts` | Tests for removed summary module |

**Project root + `src/web/` (commit `317fe50`):**

| Path | Role |
| --- | --- |
| `index.html` (project root) | Orphan from before the entry-point fix; vite never saw it because `root: "demo"` |
| `src/web/index.ts` | Loaded only by the orphaned root `index.html` |
| `src/web/renderHelpers.ts` | Used only by `src/web/index.ts` |
| `src/web/styles.css` | Same |
| `src/web/vite-env.d.ts` | Same |
| `src/__tests__/renderHelpers.test.ts` | Tested the removed helpers |

## Config edits

- `vitest.config.ts`: dropped `demo/**/*.test.ts` from `test.include` — no
  test files remain under `demo/`.

## Coverage retained

The museum dataset math is still covered by:

- `src/__tests__/museum.pipeline.test.ts` (anchors → rigid transform)
- `src/__tests__/contract.museum.v0_1.test.ts` (v0.1 contract on the
  museum fixture)

These exercise the engine via `src/core/`, not the deleted shell.

## What was kept and why

- `demo/index.html` and `demo/viewer-main.ts` — the live build entry for
  the 5-beat viewer (`root: "demo"` in `vite.config.ts`).
- `demo/public/` (museum + toy v0.1 JSON datasets) — still copied by
  `scripts/copy-demo-data.mjs` during `prebuild`. The 5-beat viewer
  imports `datasets/toy_facade_v1/*` directly through vite, so the
  copied files are no longer fetched at runtime, but pruning the copy
  pipeline is build-config work outside Phase 7's scope.
- `docs/archive/START_HERE-v0.1.md` — historical record.

## Restoring deleted files

If any removed module is wanted back, `git show <commit>:<path>` will
print its last contents. Both removal commits are on `main` once this
branch lands.
